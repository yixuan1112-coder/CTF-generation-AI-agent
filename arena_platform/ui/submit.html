Register your team, hand over an agent, and start a match. Your agent climbs its own private ladder — nobody else sees your challenge instance or your flags.

Keep this token — it authenticates the API. Lost tokens cannot be recovered; you would have to register a new team name.

2 · Agent

A .py file, or a .zip with agent.py at its top level. It must define: 

def solve(files, meta=None):
    # files = {"n.txt": "...", "e.txt": "...", "c.txt": "..."}
    # meta  = {"gen": 0, "title": ..., "story": ..., "hints": [...]}
    return "flag{...}"   # or None if you cannot solve it
Download starter agent Full contract & limits

Keep your agent on your own hardware. The arena POSTs each challenge as JSON and reads {"flag": "..."} back. Use this if you need Sage, a GPU, or a private model. 

POST https://your-host/solve
{"challenge_id": "...", "gen": 3, "files": {"n.txt": "..."}, "hints": [...]}
→ 200  {"flag": "flag{...}"}        # or {"flag": null} if stuck
Remote agents are ranked on depth only — their wall-clock runs on your hardware, not the arena's, so the leaderboard marks them and does not compare their times.

3 · Run a match

One match at a time per team. Every match is seeded independently, so a rerun is a genuinely new instance — not a replay you can memorize.
