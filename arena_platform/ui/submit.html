2 · Agent

A .py file, or a .zip with agent.py at its top level. It must define: 

def solve(files, meta=None):
    # files = {"n.txt": "...", "e.txt": "...", "c.txt": "..."}
    # meta  = {"gen": 0, "title": ..., "story": ..., "hints": [...]}
    return "flag{...}"   # or None if you cannot solve it

Ship the whole environment. You pick the base image, the interpreter and the libraries; the arena still supplies the hardware and the limits, so your times stay comparable with everyone else's. Your image owes the arena exactly two things: 

# 1. /opt/agent/agent.py defines solve(files, meta=None)
COPY agent.py /opt/agent/agent.py
RUN chmod -R a+rX /opt/agent   # the arena runs you with --user, not root

# 2. `python` is on PATH — the arena starts you with --entrypoint python
Image contract & limits

The normal route. Push your image anywhere public, then give the arena its address — nothing large crosses this connection, and shipping a fix is one docker push away.

docker build -t youruser/my-agent:v1 .
docker push youruser/my-agent:v1

For a private image, or a venue with no registry access.

docker build -t my-agent .
docker save my-agent | gzip > my-agent.tar.gz

Keep your agent on your own hardware. The arena POSTs each challenge as JSON and reads {"flag": "..."} back. Use this if you need Sage, a GPU, or a private model. 

POST https://your-host/solve
{"challenge_id": "...", "gen": 3, "files": {"n.txt": "..."}, "hints": [...]}
→ 200  {"flag": "flag{...}"}        # or {"flag": null} if stuck
Remote agents are ranked on depth only — their wall-clock runs on your hardware, not the arena's, so the leaderboard marks them and does not compare their times.

3 · Run a match
