THE SIX CORE TRACKSOpen a track to inspect its curriculum
01 / Web ExploitationApplication · Server · Database

Client security: reflected, stored and DOM XSS, CSP bypass, CSRF, SSRF, CORS, DOM clobbering, prototype pollution.

Injection: SQL injection variants, command injection, SSTI, and XXE.

Server logic: uploads, LFI/RFI, deserialization, race conditions, authentication flaws, PHP weak typing, Node.js sandboxing, and code audit.

02 / Binary ExploitationMemory · Assembly · Kernel

Foundations: x86/x64 assembly, registers, stack frames, ELF, calling conventions, NX, ASLR, Canary, PIE, and RELRO.

Stack: overflow, ret2text, ret2shellcode, ret2libc, ROP, SROP, and format strings.

Heap & advanced: ptmalloc, bins, tcache, UAF, double free, overlap, off-by-one, House techniques, kernel exploitation, ARM, MIPS and AArch64.

03 / Reverse EngineeringStatic · Dynamic · Multi-platform

Analysis: disassembly, decompilation, breakpoints, memory inspection, single stepping, IDA, Ghidra, gdb and x64dbg.

Recovery: crypto recognition, custom algorithms, mazes, matrices, Z3 constraints, anti-debugging, packers, junk code and control-flow flattening.

Platforms: ELF, PE, Mach-O, WASM, Go, Rust and native mobile libraries.

04 / CryptographyMath · Primitives · Implementation

Classical: Caesar, Vigenère, rail fence, Bacon and frequency analysis.

Symmetric: LFSR, PRNG weaknesses, AES/DES modes, CBC bit flipping and padding oracles.

Asymmetric & hash: modular arithmetic, CRT, discrete logs, lattices, RSA factorization, Coppersmith, common modulus, Wiener, ECC, invalid curves, length extension and collisions.

05 / Misc & ForensicsStego · Evidence · OSINT

Files & stego: PNG/JPEG/ZIP/PCAP repair, LSB, EXIF, watermarks, spectrograms, DTMF, zero-width text and esoteric languages.

Forensics: Wireshark/tshark, Volatility, memory images, disks, deleted-file recovery and filesystem analysis.

General: Base32/58/64/85/91, Morse, quoted-printable, archive attacks, metadata research, geolocation and OSINT.

06 / Mobile SecurityAPK · DEX · JNI

Android: APK structure, AndroidManifest.xml, classes.dex, native libraries, Activities, Services, BroadcastReceivers and ContentProviders.

Analysis: Jadx, JEB, smali, Java-layer reversing, NDK/JNI native analysis and insecure exported components.

Dynamic: Frida, Xposed, hook-based validation bypass, certificate pinning analysis and signature-check review in isolated training apps.
